# Prospector RMI — notas para Claude / agentes

App móvil (web instalable + APK) para que un geólogo encuentre arena silícea (y luego otros no metálicos) dentro de un área que dibuja en el mapa del Perú. App separada de MineLINK (Esthiven), mismo stack: React+TS+Vite+Leaflet (Vercel/Capacitor) + FastAPI (Render). Código, identificadores y textos de UI en español.

## Comandos

```bash
# Backend (desde backend/)
pip install -r requirements-dev.txt                   # = requirements.txt + pytest/httpx
uvicorn main:app --reload --port 8000                 # lee backend/.env (CDSE_*) si existe; .env no dispara --reload: tocar main.py
python -m pytest -q                                   # todas las pruebas (sin internet)
python -m pytest -q tests/test_api.py::test_clasificacion   # una sola prueba

# Frontend (desde frontend/)
npm install
npm run dev          # http://127.0.0.1:5173 ; usa VITE_API_URL o http://127.0.0.1:8000
npm run build        # tsc -b && vite build (es la única verificación de tipos; no hay linter)
npm run android:sync # build + cap sync (APK con Android Studio: android:add la 1.ª vez, android:open)
```

Pruebas: correr `python -m pytest -q` en backend/ antes de cada cambio. Levantan `tests/mock_geocatmin.py` (servidor ArcGIS REST simulado en el puerto 8799, vía `GEOCATMIN_BASE`) y prueban Sentinel con bandas sintéticas. Si se agregan capas/campos nuevos de GEOCATMIN, hay que agregarlos también al mock.

Variables: backend `CDSE_CLIENT_ID`/`CDSE_CLIENT_SECRET` (sin ellas Sentinel queda desactivado y `/health` da `"sentinel": false`), `FRONTEND_URL`, `FRONTEND_REGEX`, `AREA_MAX_KM2` (2500), `SENTINEL_MAX_KM2` (600), `GEOCATMIN_BASE`. Frontend `VITE_API_URL` (sin barra final). Deploy: `render.yaml` (Render Blueprint, rootDir backend) y Vercel con root `frontend`.

## Arquitectura

- GEOCATMIN NO envía CORS. Por eso hay dos caminos:
  - Capas de mapa: directo desde el navegador con esri-leaflet `f:"image"` + `useCors:false` (`frontend/src/Mapa.tsx`; el identify por clic funciona por JSONP gracias a `useCors:false`).
  - Datos JSON (consultas por polígono): solo vía backend (`frontend/src/api.ts` → FastAPI).
- Backend (`backend/`):
  - `main.py`: endpoints `/health` (GET+HEAD), `/materiales`, `/buscar`, `/sentinel`; CORS para localhost, Capacitor, `FRONTEND_URL` y previews `prospector-rmi*.vercel.app`.
  - `geocatmin_rmi.py`: cascada de `/buscar`. RMI, geología 50K y 100K se consultan en paralelo (la 100K SIEMPRE). Las zonas son de UNA escala (50K; 100K solo sin cobertura 50K) con su peso de clase; NO se mezclan. `anotar_respaldo_100k()` solo anota (`respaldo_100k`) las 50K B/C que una A de la 100K del MISMO tipo de material (`tipo_material`: «arena» suelta / «roca» arenisca-cuarcita; manda LITO1) cubre ≥ 30 %. `/buscar` devuelve además `afloramientos_100k` y el frontend los manda a `/sentinel` → capas `prioridad` (50K, verde), `prioridad_100k` (ámbar) y `prioridad_ambas` (máx. peso de las dos; ámbar donde solo aporta la 100K = incierto) + `celda.pct_prioridad_alta_100k/_ambas/_solo_100k`. Selector «Prioridad según la carta: 1:50 000 · 1:100 000 · Ambas» (`modoPrio` en localStorage, `CLAVE_MODO` en App.tsx): en el mapa hay UNA sola capa «Prioridad» (`s2_prioridad`); `s2Mapa` le pone la imagen del modo elegido; ⭐ Prioridad en zona libre usa el modo elegido. Toda la 100K Q-eo dice «Arenas cuarzosas formando dunas…». Sin cobertura 50K → solo 100K, como antes. Las fallas parciales de servicios no rompen la búsqueda: se agregan a `avisos`. Los polígonos se recortan al área, se agrupan por (clase, unidad, litología), se descartan los < 0.5 ha y se ordenan A→B→C y luego por área. Las capas RMI se resuelven por NOMBRE (el id es respaldo).
  - `materiales.py`: catálogo + `clasificar()`. CLASES (decisión del usuario, 21/11/2026): A = DEPÓSITOS de arena silícea/cuarzosa; B = ROCAS (arenisca cuarzosa/cuarcítica, cuarcita) y formaciones conocidas; C = verificar. Las rocas pasan por las mismas reglas de rebaje (subordinada, ígnea → C) y al final A → B (`_MOTIVOS_ROCA`). Análisis guardados antes de esa fecha traían la división vieja: `migracionClases` (App.tsx, `VERSION_CLASES`) los borra UNA vez por dispositivo al abrir la app (IndexedDB «analisis», `prospector-rmi:cuadriculas`, `prospector-rmi:barrido`); las carpetas ★ no se tocan. Si se vuelven a cambiar las clases, subir `VERSION_CLASES`. Las clases A/C se buscan en litología/descripción; la B (formación conocida) también en `UNIDAD`. Los términos de `excluir` (ígneas/volcánicas) bajan A→C y descartan C; una roca cuarzosa nombrada después de otra no cuarzosa ("lutitas con niveles de cuarcitas") baja A→C.
  - `sentinel_silice.py`: una sola petición Sentinel Hub (CDSE, L2A, mosaico de menor nubosidad en 18 meses, 7 bandas) → índices óxidos Fe, arcilla, brillo, NDVI y "pureza" por rango percentil RELATIVO al área; devuelve PNG en base64 + estadísticas por afloramiento.
- Frontend (`frontend/src/`): `App.tsx` (buscador, flujo y resultados), `Mapa.tsx` (Leaflet, dibujo del área, capas GEOCATMIN), `api.ts` (cliente y tipos; mantenerlos sincronizados con las respuestas del backend), `geo.ts` (fábrica de referencia, distancias haversine y cuadrícula de la Carta Nacional; todo del lado del cliente).
- Letras de columna de la Carta Nacional = alfabeto español CON «ñ» y SIN «w» (`ALFABETO` en geo.ts y en el script; verificado con las 501 hojas 100K de GEOCATMIN, capa 0 de SERV_GEOLOGIA_100K_INTEGRADA). Con el alfabeto inglés, todo lo que está al este de 74°30′ O sale con la letra corrida.
- Buscador universal (caja de arriba): `parsearUbicacion()` acepta 27-k / 27k4 / 27k4-NO / 25i-NO (= hoja 50K 25i4) y nombres de hoja (`GET /hojas100`); texto libre → `GET /geologia/filtro` (backend arma el SQL con `sql_texto()`: todas las palabras, cada una sin tilde o con UNA tilde, p. ej. CHIMU→CHIMÚ; nunca comodines `_`, que traían "Chambará"). "arena silícea" no existe en los mapas de INGEMMET → sinónimo de todas las unidades silíceas.
- Cuadrícula: hoja 100K = 30′ (fila desde 0° hacia el sur, letra desde 81°30′ O; "27-k Chincha" = 76°30′–76°00′ O, 13°00′–13°30′ S). Hoja 50K = cuadrante 15′ numerado como INGEMMET (campo CODHOJA, p. ej. "27k4"): 1 NE, 2 SE, 3 SO, 4 NO. Cuadrícula 1:25 000 = hoja 50K ÷ 4 (7′30″), código "27k4-NE". Fábrica por defecto: San Vicente de Cañete, Antigua Panamericana Sur (-13.0808, -76.3877), FIJA (pedido del usuario): no se arrastra ni se guarda otra ubicación. Las distancias son en línea recta, no por carretera.

Goyllarisquizga solo cuenta sin dividir (el grupo incluye Fm. Santa = calizas y Carhuaz = lutitas) y Huancané solo como "Formación" (existe un "Centro Volcánico Huancane").
